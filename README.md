# OrangeHRM QA Engineer Assignment 2026

## Project Overview

This project contains manual testing documentation and Selenium automation for the OrangeHRM demo application.

The automation validates the employee management workflow using Python, Selenium WebDriver, PyTest, and the Page Object Model (POM).

## Application

OrangeHRM Demo:

https://opensource-demo.orangehrmlive.com/

## Technologies Used

- Python 3
- Selenium WebDriver
- PyTest
- Page Object Model (POM)
- Google Chrome
- GitHub
